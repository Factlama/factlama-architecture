# Implementation rules

The architecture `ROADMAP.md` owns EPIC status; `factlama-reliability/docs/implementation.md` and `factlama-observability/docs/implementation.md` in this architecture repo own REL/OBS task status. Set `IN_PROGRESS` only when work starts, and `COMPLETE` only after acceptance criteria, contract/security/failure tests, lint/type checks, documentation and a clean-checkout validation pass. Do not mark documentation targets as implemented features. A public contract change requires compatibility analysis and an architecture ADR before implementation.
