# Architecture context

Read `EXECUTION_PLAN.md`, `SYSTEM_ARCHITECTURE.md`, `CONTRACTS.md`, `DECISION_REGISTER.md`, `SECURITY_MODEL.md`, `OPERATIONS.md` and the relevant centralized component folder before changing code. FactLama has three initial repositories: architecture owns shared contracts and component documentation, reliability owns factual evaluation code, and observability owns ingestion/query/dashboard code. The SLM is an optional judge under the provider-neutral ADR-010 qualification gate; supplied evidence is the MVP path. The Interaction Store and multi-judge ensembles are deferred.
